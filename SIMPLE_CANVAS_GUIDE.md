# Simple Canvas Implementation

## ✅ Что создано:

### 1. **useSimpleCanvas.ts** - Простое состояние

- Хранит пиксели в Map
- Базовые функции: setPixel, setZoom, setPosition
- Тестовые пиксели при инициализации

### 2. **SimpleCanvas.tsx** - Canvas компонент

- Обычный HTML5 Canvas
- Рисует пиксели как квадратики
- Поддерживает zoom и pan
- Сетка при увеличении

### 3. **CanvasArea.tsx** - Обертка

- Объединяет Canvas с координатами
- Простая структура

## 🎮 Управление:

- **Left-click**: Рисование пикселей
- **Left-click + drag**: Рисование линий
- **Alt + Mouse Wheel**: Зум
- **Right-click + drag**: Перемещение Canvas

## 🎯 Что должно быть видно:

1. **Темно-серый Canvas** в центре экрана
2. **3 тестовых пикселя** (красный, зеленый, синий) в левом верхнем углу
3. **Сетка** при увеличении (zoom > 0.5)
4. **Цветовая палитра** слева внизу
5. **Координаты** внизу по центру

## 🔧 Архитектура:

```
App.tsx
├── useSimpleCanvas (состояние)
├── CanvasArea
│   ├── SimpleCanvas (рисование)
│   └── CoordinatesDisplay (координаты)
├── ToolsPanel (цвета)
└── Header (навигация)
```
